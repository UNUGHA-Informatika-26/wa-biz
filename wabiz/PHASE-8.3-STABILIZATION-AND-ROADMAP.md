### Persyaratan khusus lintas fase

- **Campaign:** consent evidence/opt-out before eligible recipient; normalize/validate number; tenant/connection ownership; per-provider rate limit; duplicate guard; separate known failure from ambiguous `unknown`; never blindly retry unknown; preview/count and safe stop/cancel.
- **AI:** source of truth is current organization settings + active generation. Unknown facts return unavailable; registration URL only from valid persisted setting. AI processing disabled for human-owned/resolved states; fake tests assert no provider send after stale job/handoff/reset. Gemini credentials remain backend-only.
- **Reset:** current design increments `history_generation`; it is a context reset, not permanent deletion. Preserve message history for audit unless owner approves a retention/delete policy. Document which views see older generations and retention/access rules.
- **Handoff:** same-tenant current connection, active CS membership, normalized valid CS recipient; record actor/status/attempt. Failed/unknown recovery requires authorized explicit action; explain duplicate risk when provider outcome is ambiguous. Notification to CS is not a transfer of the customer's WhatsApp thread to a CS-owned session.
- **Tenant safety:** no Flutter-supplied organization authority. Every client/conversation/message/campaign/setting/connection/member resolves from authenticated organization or trusted session mapping. Negative cross-tenant tests are release gates.
- **Gateway:** loopback `127.0.0.1:21465`, `startAllSession:false`, request gates remain unchanged. No exposing secret/session token in Flutter, public port, logs, or report.

4. Jangan menguji callback valid yang dapat memanggil AI processor kecuali test dipastikan memakai fake AI/provider dan side effect outbound diblokir.
5. Jangan scan QR, login/pair WhatsApp, membuat session, menjalankan campaign, mengirim pesan, menghubungi nomor CS/client, atau melakukan real provider delivery.
6. Jangan mengubah/mengganti baseline atau restore file berdasar hash saja.
7. Jangan memasang kredensial ke Flutter, browser screenshot, terminal transcript, atau laporan. Jangan membaca/mencetak `.env`.
8. Jangan deploy sebelum HTTPS host/base URL, callback log redaction, secret rotation status, consent policy, worker/scheduler supervision, backup restore, monitoring, rollback, dan tenant tests memenuhi gerbang.
